# Nova Activations (frontend demo, first pass)
Static HTML/CSS/vanilla JS. Run with VS Code Live Server (ES modules need http).
Built: home, shop, product, cart, checkout, confirmation. Demo codes: NOVA10, WELCOME5.
Data lives in localStorage (demo only, not secure). Reset: clear keys starting `na_`.
No real payments or licence keys. Not yet built: auth, dashboard, orders, activations, support, admin, extra pages.
